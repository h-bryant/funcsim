Regret-Theoretical Expected Utility
===================================

Regret-theoretical expected utility (RTEU) and menu-based certainty
equivalents for one scenario at a time, given the best attainable
outcome in each state of nature across the decision maker's menu, with a
power regret function as a building block.  See :doc:`guide_utility` for
a narrative introduction with examples.
