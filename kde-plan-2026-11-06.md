# Plan: univariate KDE improvements (2026-11-06)

Three independent additions to `funcsim.Kde` (`funcsim/kde.py`), to be
implemented one per session, in this order:

1. bounded support by reflection (plus the internal refactor the other two
   steps rely on);
2. a least-squares cross-validated bandwidth, `bw='lscv'`;
3. a Sheather-Jones plug-in bandwidth, `bw='sj'`.

Constraints that apply to every step:

- **No new dependencies.** Everything below uses NumPy, `scipy.special`
  (`ndtr`, `ndtri`), `scipy.optimize`, and `scipy.stats.gaussian_kde`, all
  already required.  statsmodels, KDEpy, and scikit-learn are not to be
  imported, not even optionally.  R (`/opt/homebrew/bin/Rscript`) is used
  only by hand to generate reference numbers that are then pasted into
  tests with the R snippet that produced them in a comment.
- **Existing results must not change.** For `bw='scott'`, `bw='silverman'`,
  and a float `bw`, with no bounds, `pdf`, `cdf`, and `ppf` must agree
  with version 0.2.9 to at least 1e-12 relative.  Step 1 begins by pinning
  reference values from 0.2.9 in a regression test.
- Public API after all three steps:

  ```python
  Kde(data, bw='scott', lowerBound=None, upperBound=None, exact_ppf=False)
  # bw: 'scott' | 'silverman' | 'lscv' | 'sj' | positive float (kernel sd)
  ```

  `lowerBound` and `upperBound` take `None` or a finite float, never a
  bool, exactly as `fit` and `compare` do.  Reuse `_validate_bound` and
  `_check_bounds_against_data` from `funcsim/distfit.py` (move them to a
  small shared module if importing `distfit` from `kde` is awkward).  Data
  exactly on a bound is allowed; data beyond a bound raises `ValueError`.
- `MvKde` keeps accepting only `'scott'` and `'silverman'`; the divergence
  is documented in both classes.
- Status: step 1 implemented 2026-11-06 (bound validators now live in
  `funcsim/bounds.py`; regression test `tests/test_kde_regression_0_2_9.py`;
  bounded tests `tests/test_kde_bounds.py`).  Step 2 implemented
  2026-11-06 (`tests/test_kde_lscv.py`); see the note at the end of 2b
  and 2c.  Step 3 implemented 2026-11-06 (`tests/test_kde_sj.py`); see
  the note at the end of 3b.  All three steps are done; the version is
  still 0.2.9 pending a release.
- Each step ends with: tests passing, the class docstring and
  `docs/source/guide_distributions.rst` updated, the Sphinx build clean
  with `-W`, and a version-bump release commit per the usual convention.

Notation used throughout: observations `x_1..x_M`, bandwidth `h` (the
kernel standard deviation, in data units), `phi_h(t) = phi(t/h)/h`,
`Phi` the standard normal CDF, `s` the sample standard deviation with
`ddof=1`.  The unbounded estimator is

```
fhat(x) = (1/M) sum_i phi_h(x - x_i)
Fhat(x) = (1/M) sum_i Phi((x - x_i)/h)
```

with `h_scott = M^(-1/5) s` and `h_silverman = (3M/4)^(-1/5) s`.

## Step 1: internal refactor and reflection

### 1a. Refactor (no behavior change)

Goal: make the estimator a function of (data, `h`, bounds) so that the
bounded formulas and the bandwidth selectors can share one code path.

- Compute `h` inside `Kde.__init__` (rules of thumb from the formulas
  above, or the float), and construct `self.gkde` as
  `stats.gaussian_kde(data, bw_method=h / s)`.  `self.gkde` stays public
  and stays the *unbounded* KDE of the original data, so the `bandwidth`
  property and `tests/test_kde.py` (which compares `pdf` with
  `kde.gkde(x)`) keep working.  Never fit scipy on augmented data: scipy's
  rules of thumb would then use the wrong `M` and the wrong `s`.
- Replace the Python loop over `integrate_box_1d` in `_cdf_array` with a
  chunked `ndtr` sum (the same pattern as `_PpfTable.__init__`, chunking so
  the grid-by-data intermediate stays under about 2e6 elements).  Provide
  both `_F(x)` and `_S(x)` (survival, from `ndtr(-z)`) helpers; the table
  needs both for precision in the upper tail.
- Change `_PpfTable` to take `(centers, weights, h, lo, hi)` plus a CDF
  callable rather than a `gaussian_kde`, so step 1b can hand it the bounded
  CDF.
- Pin regression values first: for three fixed-seed samples (normal,
  lognormal, n=20) record `pdf`, `cdf`, `ppf` at a handful of points under
  0.2.9 and assert agreement to `rtol=1e-12` after the refactor.

### 1b. Reflection (Schuster, 1985; Silverman, 1986, sec. 2.10)

Images: for a lower bound `a` the image of `x_i` is `2a - x_i`; for an
upper bound `b` it is `2b - x_i`.  Second-order images (`2a - (2b - x_i)`
and so on) are omitted; their mass on the support is below machine
precision when `(b - a)/h >= 8`, and the normalization below absorbs the
remainder when it is not.

Density on the support (zero outside it):

```
f_R(x) = [ fhat(x) + [a] fhat(2a - x) + [b] fhat(2b - x) ] / Z
```

where `[a]` and `[b]` are 1 when that bound is given and 0 otherwise.

CDF: define

```
G(x) = Fhat(x) - [a] Fhat(2a - x) + [b] (1 - Fhat(2b - x))
lo = a if given else -inf;  hi = b if given else +inf
Z  = G(hi) - G(lo)
F_R(x) = (G(x) - G(lo)) / Z          for lo <= x <= hi, else 0 or 1
```

Checks: with a lower bound only, `G(lo) = 0` and `Z = 1` exactly; with an
upper bound only, `G(-inf) = 0` and `Z = 1` exactly; with both,
`Z = Fhat(2b - a) - Fhat(2a - b)`, which is one minus the mass of the
images that leaks past the opposite bound.  Compute the survival
counterpart `S_R(x) = (G(hi) - G(x)) / Z` from `ndtr(-z)` terms rather than
as `1 - F_R`.

Properties to document: `f_R` integrates to one on the support, is
nonnegative, and has zero slope at each bound.  Reflection is unbiased at
a bound only when the true density is flat there; otherwise the boundary
bias is of order `h` (for example an exponential density at zero).
Boundary-kernel corrections (Jones, 1993) fix that but can be negative,
which would break `ppf`, so they are deliberately not offered.  A log
transform for positive data is a possible later alternative.

### 1c. Inverse CDF with bounds

- `ppf(0)` returns `lo` and `ppf(1)` returns `hi` exactly when that bound
  is given (handle `u == 0` and `u == 1` before consulting the table);
  the unbounded ends keep the current behavior.
- The root-finding bracket becomes `[lo or ppf_low, hi or ppf_high]`.
- The table grid spans `[max(lo, min - 8h), min(hi, max + 8h)]`.  At a
  bound, `F_R` is exactly 0 (or 1) and goes to zero linearly, so the
  normal score is `-inf` there (already dropped by the `keep` mask) and
  `x(q)` is strongly curved near the bound (`x - a` is about
  `Phi(q) / f_R(a)`).
- **Implemented (2026-11-06), after measurement:** PCHIP's secant-based
  derivatives are only third-order accurate, and on that curved stretch
  they limit the table to about 1e-6 of the range however the grid points
  are placed (denser geometric points made it worse).  With a bound the
  table therefore uses `scipy.interpolate.CubicHermiteSpline` with the
  exact derivative `dx/dq = phi(q) / f_R(x)`, clipped to three times the
  smaller adjacent secant (Fritsch and Carlson, 1980) so it stays
  monotone, on the uniform grid plus, next to each bound, the first 16
  cells subdivided 8 times and geometric points `R * 2^-k`, `k = 13..40`.
  That reaches about 1e-8 of the range in every test case, with at most
  one derivative clipped.  Unbounded tables keep PCHIP unchanged, so
  0.2.7 to 0.2.9 results are reproduced exactly; unifying on the Hermite
  scheme would change unbounded `ppf` values at the 1e-9 level and is left
  for a later version.

### 1d. Tests (`tests/test_kde_bounds.py`)

- Regression values from 0.2.9 (see 1a).
- `cdf(lo) == 0`, `cdf(hi) == 1`, `ppf(0) == lo`, `ppf(1) == hi`, `pdf`
  and `cdf` zero / one outside the support.
- Mass: `cdf(hi) - cdf(lo)` is 1 to 1e-12; `scipy.integrate.quad` of
  `pdf` over the support is 1 to 1e-8.
- Uniform on `[0, 1]` with both bounds: `pdf` is within a few percent of
  1 everywhere on `[0.001, 0.999]` for M = 2000 (reflection makes the
  estimate almost exactly flat; the unbounded KDE is near 0.5 at the
  ends).  This is the strongest single test of the formulas.
- Half-normal with `lowerBound=0`: `pdf(0)` is close to `2 phi(0)`.
- Consistency with the augmented-sample construction: for a lower bound,
  `pdf(x)` equals `2 * gaussian_kde(concat(x, 2a - x), bw_method=h/s_aug)(x)`
  on the support to 1e-12.
- `ppf` is nondecreasing on a dense `u` grid; `cdf(ppf(u))` round-trips.
- Validation: bool bound raises `TypeError`; `lowerBound >= upperBound`,
  a non-finite bound, or data beyond a bound raises `ValueError`; data
  exactly on a bound is accepted.
- `bandwidth` is unchanged by bounds for `'scott'`, `'silverman'`, and
  float `bw`.

## Step 2: least-squares cross-validation, `bw='lscv'`

Criterion (Rudemo, 1982; Bowman, 1984), targeting integrated squared
error:

```
LSCV(h) = int f^2 - (2/M) sum_i f_{-i}(x_i)
```

where `f_{-i}` is the estimate without observation `i` (divide by
`M - 1`).  With the Gaussian kernel both terms are closed-form pairwise
sums, so no numerical integration is needed.

### 2a. Unbounded case

With `d_ij = x_i - x_j`:

```
int fhat^2           = (1/M^2) sum_{i,j} phi_{h sqrt2}(d_ij)     (includes i = j)
(2/M) sum f_{-i}(x_i) = (2/(M(M-1))) sum_{i != j} phi_h(d_ij)
```

### 2b. Bounded case (this is the interaction with step 1)

The criterion must be evaluated for the *reflected* estimator.  Running
LSCV on the raw data and then reflecting is wrong in a predictable
direction: the unbounded estimator's boundary bias pulls the criterion
toward a smaller `h` than the reflected estimator needs.

Let `C_i` be the set of centers for observation `i` (`x_i` and its one or
two images), and treat `Z = 1` (the normalization matters only when
`(b - a)/h < 8`; document this).  Then

```
int_lo^hi f_R^2 = (1/M^2) sum_{i,j} sum_{c in C_i, c' in C_j}
                  phi_{h sqrt2}(c - c') * W(c, c')
W(c, c') = Phi((hi - m) / (h/sqrt2)) - Phi((lo - m) / (h/sqrt2)),  m = (c + c')/2
f_{R,-i}(x_i) = (1/(M-1)) sum_{j != i} sum_{c' in C_j} phi_h(x_i - c')
```

The weight `W` comes from the product of two Gaussians being a Gaussian
in the difference times a normal density in `x` with mean `m` and
variance `h^2/2`.  The leave-one-out estimate drops observation `i`
together with all its images.  With no bounds, `W = 1` and `C_i = {x_i}`,
so 2a is the special case; implement only the general form.

**Implemented (2026-11-06):** with a single bound the reflected density
extended across the bound is symmetric about it, so the integral over the
support is half the unweighted integral over the line and `W` is not
needed; `W` from the midpoints is used only with two bounds.  The
pairwise sum is taken once over `k <= l` by symmetry.  The closed form
agrees with brute-force quadrature plus leave-one-out refits to 1e-15 in
all four bound configurations.

### 2c. Search

- Grid: 25 log-spaced `h` in `[h_scott/20, 4 h_scott]`.
- Take the **largest local minimizer** on the grid (Hall and Marron,
  1991; the criterion commonly has several minima, and spurious ones sit
  at small `h`), then refine with `scipy.optimize.minimize_scalar`
  (bounded) between its grid neighbors.
- `warnings.warn` when the minimum is at either end of the grid (lower
  end: undersmoothing collapse, often from tied or rounded data; upper
  end: the data may be nearly uniform, where ever larger `h` is optimal
  under reflection), and when the data contain many ties.  Still return
  the value.
- Cost: `O(M^2 * n_centers^2)` per evaluation.  When the pairwise arrays
  (differences and, for bounded data, midpoints) fit in about 100 MB,
  precompute them once and vectorize each evaluation; otherwise recompute
  in chunks.  Document that `'lscv'` is intended for samples up to a few
  thousand observations.

Likelihood cross-validation is deliberately not offered (inconsistent for
heavy tails, pulled to oversmoothing by any outlier).  Biased
cross-validation (Scott and Terrell, 1987) is a possible later addition.

### 2d. Tests (`tests/test_kde_lscv.py`)

- Closed form against brute force: for M = 40 and several `h`, compute
  `int f^2` by `scipy.integrate.quad` (over the support, bounded and
  unbounded) and the leave-one-out term by an explicit loop using the
  public `pdf` of a `Kde` built on the reduced sample; agree to 1e-8.
  This validates the bounded formula in 2b in particular.
- Normal sample, M = 500: `h_lscv` within a factor of 2 of `h_scott`.
- R reference (unbounded): fixed-seed samples, compare with
  `bw.ucv(x, nb = 1e6, lower = ..., upper = ..., tol = 1e-10)` (R bins
  pairwise distances and its default `tol` is coarse).  **Note:** R's
  criterion is the Scott-Terrell form with `1/n^2` in both terms, while
  the form above has `1/(n(n-1))` in the leave-one-out term, so agreement
  is only to order `1/n` (observed -1.2%, -0.28%, -0.16% at n = 100,
  500, 2000); the strict correctness check is the brute-force test.
- Ties: a rounded sample triggers the warning.
- `bandwidth` reports the selected value; `pdf`, `cdf`, `ppf` are then
  identical to `Kde(data, bw=that float, ...)`.

## Step 3: Sheather-Jones plug-in, `bw='sj'`

Solve-the-equation rule (Sheather and Jones, 1991; Wand and Jones, 1995,
sec. 3.6), following the form in R's `bw.SJ(method = "ste")`.

### 3a. Ingredients

Kernel functional estimates, for even `r`:

```
psi_r(g) = (1 / (M^2 g^(r+1))) sum_{i,j} phi^(r)((x_i - x_j)/g)   (includes i = j)
phi^(4)(z) = (z^4 - 6 z^2 + 3) phi(z)
phi^(6)(z) = (z^6 - 15 z^4 + 45 z^2 - 15) phi(z)
```

Scale and pilot bandwidths (R's constants, equal to Sheather and Jones's
0.920 and 0.912 times 1.349):

```
lam = min(s, IQR / 1.349)
a   = 1.24 * lam * M^(-1/7)       # pilot for psi_4
b   = 1.23 * lam * M^(-1/9)       # pilot for psi_6
TD  = -psi_6(b)                   # positive
c1  = 1 / (2 sqrt(pi) M)          # R(K) / (mu_2^2 M) for the Gaussian kernel
alpha2(h) = 1.357 * (psi_4(a) / TD)^(1/7) * h^(5/7)
```

Equation to solve for `h`:

```
(c1 / psi_4(alpha2(h)))^(1/5) - h = 0
```

Bracket `[0.1 hmax, hmax]` with `hmax = 1.144 lam M^(-1/5)`; if the
function has the same sign at both ends, widen (alternately `upper *= 1.2`,
`lower /= 1.2`) up to a fixed number of times, then raise `ValueError`
with a message suggesting `'lscv'` or a float.  Solve with
`scipy.optimize.brentq`.

Also implement the non-iterative direct plug-in variant first, as a
stepping stone and as a fallback that is easy to test
(`bw.SJ(method = "dpi")`):

```
g = (2.394 / (M * TD))^(1/7);   h = (c1 / psi_4(g))^(1/5)
```

Expose only `'sj'` (the solve-the-equation rule) publicly; keep `dpi` as
a private helper unless a reason to expose it appears.

Cost: `O(M^2)` per `psi_r` evaluation, roughly 10 to 20 evaluations in
the root search.  Same precompute-or-chunk rule as step 2.

### 3b. Bounded case (the interaction with step 1; heuristic only)

The plug-in rule rests on the `h^4` bias expansion, which the reflected
estimator does not satisfy unless the true density has zero slope at the
bound.  Estimating the functionals on the raw data is also contaminated
by the boundary (the curvature estimates inflate, giving too small an
`h`).  Decision: compute the functionals on the reflected sample, treated
as a sample from the symmetric extension of `f`, and document it as a
heuristic.

Concretely, with `n_img` the number of centers per observation (2 for one
bound, 3 for two):

- `lam` from the original data, `M` the original sample size everywhere
  (`c1`, the pilot bandwidths, the `M^2` in `psi_r` replaced by the
  number of centers squared).
- `psi_r` computed as the pairwise sum over **all centers**, then
  multiplied by `n_img`.  Reason: if `f~` is the symmetric extension
  (each copy carrying mass `1/n_img`), then
  `int (f'')^2 over the support = n_img * int (f~'')^2 over the line`.
  The factor cancels in `alpha2` (a ratio) and matters only in the final
  equation.
- Document: when the true density has a nonzero slope at a bound (an
  exponential at zero), `'sj'` with bounds undersmooths; prefer `'lscv'`
  there.  A log transform for positive data, on which the plug-in rule is
  exact, is the principled alternative for a later version.

**Implemented (2026-11-06):** the functionals follow R's `bw.SJ`
conventions exactly (sum over all pairs including the diagonal, divided
by `N (N - 1) g^(r+1)`), so the unbounded rule agrees with R to a few
parts per million (R's binning is the limit).  The expected
undersmoothing at a nonzero-slope bound did not materialize in the test:
for an exponential sample bounded at zero the heuristic gives a bandwidth
twice the unbounded rule's and within a few percent of the bounded LSCV
choice; the folded-normal check gives a ratio of 0.859 against the
expected 0.871.  The docs state the heuristic status and point to
`'lscv'` as the guaranteed option with bounds.  `dpi` is implemented as a
private option of `_sj_bandwidth` and tested against R but not exposed.

### 3c. Tests (`tests/test_kde_sj.py`)

- Functional estimates against an explicit double loop for M = 30
  (1e-12), including the diagonal terms.
- R reference (unbounded): fixed-seed samples of size 100, 500, 2000
  (normal, lognormal, bimodal); compare with `bw.SJ(x, nb = 1e5)` for
  `method = "ste"` and `"dpi"` to `rtol=2e-3`.  Paste numbers and the R
  snippet into the test.  Check how close agreement actually is with a
  large `nb` and tighten the tolerance accordingly.
- Normal sample, M = 1000: `h_sj` within 20% of `1.06 s M^(-1/5)`.
- Bounded sanity check with a closed-form expectation: for `Z ~ N(0,1)`,
  `|Z|` with `lowerBound=0` has `int (f'')^2` on `[0, inf)` equal to twice
  that of the normal density, so `h_sj(|Z|, lowerBound=0)` should be
  about `2^(-1/5) = 0.87` times `h_sj(Z)` for the same draws.  Assert
  within 10% for M = 2000.
- Consistency: `psi_4` on the folded sample with a lower bound at 0
  equals `psi_4` computed directly on `concat(Z, -Z)` (the reflected
  sample of `|Z|` about 0 is exactly that set).
- The bracket-widening failure path raises `ValueError` (construct a
  pathological sample, for example two tight clusters of identical
  values, or monkeypatch the widening limit).
- `bandwidth` reports the value; `pdf`, `cdf`, `ppf` match
  `Kde(data, bw=that float, ...)`.
